# Inventory Tracker

**Author:** Kolade Afolabi
**Course:** SEN 401 - Software Configuration Management and Maintenance (Lab 3)

A small Python project that keeps a list of stock items and calculates the
total stock value.

## Files

| File | Purpose |
| --- | --- |
| `inventory.py` | List of items, each with `item_name`, `quantity` and `price` |
| `app.py` | Reads the inventory and calculates the total stock value |
| `utils/helpers.py` | `highest_stock_item()` and `lowest_stock_item()` |
| `requirements.txt` | Python dependencies (none) |

## How to run

```bash
python app.py
```
